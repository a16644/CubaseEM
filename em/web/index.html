触发器那一格按「触发方式」换专用的输入框：按键 / 双键 → 填音名； 按通道切换 → 只填通道号（1–16）；通道＋按键 → 键位 + 通道； CC 控制器 → CC[号]=[值] 两个框各填各的，不用打「CC4=100」这种字符串。
灰斜体的 ≈值 是按同类格子的规律推出来的建议 （改哪个字段就推哪个字段，挂在那个字段自己那个框后面），点一下就采用。
触发一条技法的不止是按键 —— 通道、CC 号 / CC 值同样算触发。 所以在「更多细则」里填了通道、键位留空时，触发器那格会出现蓝标 通道 3， 点一下能把触发方式也改成「按通道切换」。
表格列宽能自己调：拖表头右边缘就行（双击那一列恢复默认）， 每列都有最低宽度、总宽超了会横向滚动 —— 不会再出现标签把输入框盖住、看不见填了什么。 调过的列宽会记住，想回到初始值点上面的列宽复位。
空着的触发键要不要替你补，由「更多设置」里的 自动补触发键 决定，默认是关的： 关着 = 留空就留空，触发键直接不写（key = -1），靠通道 / CC 触发； 打开了才从「自动分配的起始键」往后补一个键位（等于多按一个键）。 下面「更多细则」展开后，↑↓ 换行、Tab 换到下一行的同一个框； 换行时表格和细则始终跟着同行走。

「触发方式」都是什么意思？
按键切换最常用的一种。按一个键代表切到这个技法（比如按 C0 = Legato）。默认就选它。
双键齐按两个键同时按下才生效。一般用于组合技法，也可以单独用。
按通道切换不按键，改用 MIDI 通道区分（一个技法占一条通道）。
通道＋按键先认通道，再在该通道上用按键切换。
CC 控制器用 MIDI CC 消息（弯音轮、表情踏板这一路）来切。填法：CC4=100。
常驻，不切换不用任何键，这条永远生效。通常留给默认音色。

组合技法

有些音色需要两个技法同时挂着才出得来声，比如「Legato ＋ 颤音」。 Cubase 里 Art.1～Art.4 是四个可以同时开着的条件行， 所以做法是：做一个组合槽位，它把两个技法的键一起按下去。
