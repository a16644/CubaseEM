# config —— 运行时配置（部分文件不进版本库）

这里放程序运行中要读写的小数据。clone 下来第一次运行时会自动创建这个目录。

| 文件 | 是什么 | 进版本库吗 |
|---|---|---|
| `palette.json` | 16 个显示色（改色号后刷新网页生效） | ✅ 进，通用预设 |
| `combo_presets.json` | 组合技法的预设模板 | ✅ 进，通用预设 |
| `techniques.json` | **你自己的技法库**（存着各个音源的技法条目） | ❌ 不进，`.gitignore` 已排除 |
| `settings.json` | **你自己的界面偏好**（缩放、列宽、导出目录…） | ❌ 不进，`.gitignore` 已排除 |
| `libs/` | **你保存的技法库文件** | ❌ 不进，`.gitignore` 已排除 |

`techniques.json` 之类的文件被排除了，是为了不让个人积累的数据跟着仓库一起公开。
想要一份干净的初始文件，直接跑一次程序就会生成；也可以手工建一个：

```json
{"version": 1, "updated": "", "items": []}
```
